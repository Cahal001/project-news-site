# News Site
The assignment was to create a new site. This is my attempt.
I have created a made up news paper that focuses on knitting.
The project is the first assignment of the self-paced web developer bootcamp.

## The problem
To design the project I turned to a classic pen and paper and then played around with Figma to design the page.

When I started to build the page in VSC I did alot of research of how to do things in the best way. W3Schools came in handy for learning tricks.
I've been working in CodePen to try things out and then created the page in VSCode.

My computer crashed mid project and I had to start all over. Therefore I have multiple backups now.
If I were to make a similar page or if I had more time to develop this one I would create a sidebar with the latest news articles.

I think it will be easier to plan a project ahead when I've learned more about building web pages.
Learing along the way has also made me change the page, probably, a thousand times to many.
